# Image Tune — Penpot plugin

Non-destructive photo adjustments for image fills in Penpot, with live GPU preview.

**Install in Penpot:** Plugins → paste `https://studioreviofc-wq.github.io/penpot-image-tune/manifest.json`

- **Light:** exposure, contrast, highlights, shadows, whites, blacks
- **Color:** temperature, tint, vibrance, saturation, hue
- **Detail:** sharpness, clarity · **Effects:** vignette, grain, fade
- 12 looks with live thumbnails, Auto adjust, live histogram, hold to compare before/after
- **Editable mode:** the original stays inside the layer and settings are saved on it — reopen to readjust or restore anytime. Or flatten.
- Apply to many layers at once, copy/paste settings
- Runs 100% in the browser (WebGL) · English, Português, Español
